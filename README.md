# Mega menu preview

Demo del megamenú con el mapa del cliente, usando el sistema visual de [Lucid](https://lucid.co/es/soluciones): cabecera, logo, colores (`#282c33`, `#005ed0`), hero y columnas.

Abrir `index.html` en el navegador, o servir la carpeta. En escritorio, pasar el cursor entre **Soluciones** e **Industrias**. En tablet/móvil, usar el menú hamburguesa.

## Navegación (demo)

- **Soluciones** — Real-Time Interpretation (OPI, VRI, On-Site + Use cases), Schedule interpretation, Infrastructure / LaaS
- **Industrias** — Healthcare, Legal, Enterprise, Government, Education (Risks, Use Cases, Outcomes)

## Construcción

- Prefijo de clases `mm_` para migrar a Webflow.
- Variables CSS para paleta y tipografía.
- Animación de entrada 200 ms. Hover: el contenedor del icono se ilumina.
- Responsive: sheet + pestañas en ≤991px.
